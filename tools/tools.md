# Tools and Libraries

## 1. LM-Polygraph
**Purpose:** Toolkit and benchmark for uncertainty estimation methods for LLM text generation, including methods useful for hallucination detection.  
**Official project:** https://github.com/IINemo/lm-polygraph

## 2. Semantic Uncertainty
**Purpose:** Reference implementation for semantic uncertainty / semantic entropy experiments.  
**Official project:** https://github.com/jlko/semantic_uncertainty

## 3. UQ-NLG
**Purpose:** Reproducible code for uncertainty quantification experiments in natural language generation.  
**Official project:** https://github.com/zlin7/UQ-NLG

## 4. Ragas
**Purpose:** Framework for evaluating RAG pipelines, including faithfulness-oriented evaluation.  
**Official project:** https://github.com/vibrantlabsai/ragas

## 5. SelfCheckGPT
**Purpose:** Black-box hallucination detection through consistency checking across sampled generations.  
**Official project:** https://github.com/potsawee/selfcheckgpt

## 6. UNCERTAINTY-LINE
**Purpose:** Length-invariant correction of uncertainty estimates for LLM outputs.  
**Official project:** https://github.com/stat-ml/uncertainty-line
