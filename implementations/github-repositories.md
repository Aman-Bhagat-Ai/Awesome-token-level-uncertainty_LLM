# GitHub Implementations

Selection criteria follow the assignment: documentation, source availability, maintenance/activity, examples, reproducibility, license, and connection to a research paper/project—not stars alone.

## 1. SelfCheckGPT
- **Repository:** https://github.com/potsawee/selfcheckgpt
- **Implements:** Sampling-based black-box hallucination detection with multiple checking variants.
- **Why relevant:** Strong black-box baseline against which token-level/white-box uncertainty methods can be compared.

## 2. Semantic Uncertainty
- **Repository:** https://github.com/jlko/semantic_uncertainty
- **Implements:** Generation, uncertainty computation, and evaluation pipelines for semantic uncertainty experiments.
- **Why relevant:** Directly connects uncertainty estimation with hallucination detection.

## 3. LM-Polygraph
- **Repository:** https://github.com/IINemo/lm-polygraph
- **Implements:** Collection of uncertainty-estimation methods and evaluation tooling for LLM generation.
- **Why relevant:** Useful for comparing multiple uncertainty estimators in a common framework.

## 4. ALCE
- **Repository:** https://github.com/princeton-nlp/ALCE
- **Implements:** Data, baselines, and automatic evaluation for citation-generating LLMs.
- **Why relevant:** Connects factuality, citation support, and evaluation of trustworthy generation.

## 5. TruthX
- **Repository:** https://github.com/ictnlp/TruthX
- **Implements:** Inference-time representation editing to increase truthfulness.
- **Why relevant:** Demonstrates how internal model representations can be manipulated to reduce hallucination.

## 6. RAGTruth
- **Repository:** https://github.com/ParticleMedia/RAGTruth
- **Implements:** Dataset release and baseline/evaluation code for word-level RAG hallucinations.
- **Why relevant:** Provides fine-grained hallucination evaluation complementary to token uncertainty.
